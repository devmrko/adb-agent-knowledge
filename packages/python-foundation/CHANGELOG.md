# Changelog

## 0.1.0 — 2026-10-15

Initial private foundation: typed error contracts, SQLAlchemy UnitOfWork, FastAPI request/error adapters,
server-side session and JWT authentication, bounded HTTP clients, Project CRUD/HTML example,
Alembic migration, project generator, wheel consumption checks and Java-compatible HTTP contract.

No public PyPI release, production session backend, durable worker implementation or real Oracle certification.
