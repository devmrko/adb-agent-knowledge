# v3 버전 원문·그래프 연결 파일럿

현재 v2 운영 경로와 별도로 실행하는 **v3 첫 구현**입니다. 신규 릴리스나 운영 이관 완료가 아닙니다.

## 구현된 경로

```text
v2 정확한 원문 버전 → SourceEnvelope JSON → Agent Memory 버전별 record_id
                                    └→ 기존 한국어 청크 → SDK 벡터 저장/검색
SDK 검색 결과 → knowledge_id + revision_id → 현재 원문/상태 검사
                                          → 기존 RDF 검증 + Property Graph 관계 탐색
```

- `knowledge_app/v3_pilot.py`: 소유자/지식/버전별 안정적인 ID, 불변 JSON, 해시 검증, 멱등 재시도.
- 과거 원문은 덮어쓰지 않습니다. 현재 검색은 기존 현재 버전·상태 기준으로 제한합니다.
- 관계의 근거 ID는 그대로 유지하므로 기존 RDF·Property Graph를 함께 사용할 수 있습니다.
- SDK 오류를 외부 원문 그대로 노출하지 않습니다. 성공 여부가 불확실하면 같은 ID로 상태를 확인합니다.

이 단계는 실제 서비스 메서드/SDK/DB 연결 시험이며 새 MCP/API 기본 경로를 배포한 것은 아닙니다.

## 실행

분리된 테스트 계정(VKV_ 또는 OAM_TEST_ 접두사)에 기존 앱 마이그레이션과 RDF/Property Graph를
준비한 다음 실행합니다. 관리자 계정·운영 스키마 실행은 거부합니다.

```sh
./uvw sync --extra agent-memory
./.venv/bin/python -m scripts.smoke_v3_pilot \
  --env-file /path/to/isolated-test.env \
  --output .run/v3-pilot/result.json
# 이미 준비된 모델 캐시를 오프라인으로 사용하려면 --hf-home /path/to/huggingface 추가
```

고정 모델 revision은 `55ec6e9358a56d56af759bc8372e970caf8c305f`입니다.
독립 SDK store `V3PILOT1103`와 합성 문서3건을 사용합니다. 재실행은 별도 시험 소유자로 자료를 추가합니다.
자료를 자동 삭제하거나 기존 store를 재생성하지 않습니다. 중단된 시험 데이터/작업은 테스트 계정에 남을 수 있습니다.

## 첫 파일럿의 범위와 후속 단계

이 절은 첫 파일럿 당시의 제약입니다. 이후 [재개 가능한 원문 이관·선택적 조회 전환](v3-source-transfer.md)을
추가했습니다. 운영 기본값은 여전히 v2이며 아래 검색·파일·규모 검증 과제는 남아 있습니다.

### 첫 파일럿의 제약

현재 원문·수명 판정과 그래프의 인용 검증은 v2에 의존합니다. 파일 원본 바이트는 SDK에 이관하지 않습니다.
독립 v3 원문 조회 인터페이스, durable 전환 작업과 활성화 트랜잭션, 재개 가능한 backfill, 파일/추출
메타데이터 전부의 대응, 검색 동등성 검증이 남아 있습니다. 검색 후보는 최대100개이며 그 안에서
과거 버전을 제외하므로 많은 이력이 있으면 누락이 생길 수 있습니다. 응답에 한도 도달을 표시합니다.
동시 프로세스의 첫 쓰기 경쟁도 아직 통합 검증하지 않았습니다.

이 단계의 되돌리기는 기존 v2 읽기 경로가 그대로 동작하는지 비교하는 것입니다. 이미 활성화된 v3를
운영에서 되돌리는 완성된 마이그레이션 절차는 아닙니다. 두 저장소 복사본은 비교 시험용이며 최종 구조가 아닙니다.

## 2026-11-03 실제 검증 결과

- 분리 Oracle 계정에서 합성 문서3건을 고정 한국어 모델로 색인, SDK 검색 결과에 대상 문서 포함 확인.
- 원문 JSON 왕복·동일버전 재시도·타사용자 차단 확인.
- SDK 원문 버전 → RDF 검증 → Property Graph 관계 탐색, 관계형 탐색 결과와 일치.
- 수정 후 과거 SDK 원문 보존, 현재 검색/관계에서 이전 근거 제외, 새 원문 근거 연결 확인.
- 기존 v2 검색과 과거 원문 조회가 그대로 동작하는 것 확인.
- 전체293개 테스트 및 ruff/format/mypy 통과. [실행 결과](../reference/v3-pilot-validation.json).

성공한 작은 경로 시험이며 대규모 검색 품질·성능·완전한 운영 이관 검증은 아닙니다.
