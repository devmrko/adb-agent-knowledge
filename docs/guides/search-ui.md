# 지식 검색 화면

API 실행 후 http://127.0.0.1:8000/knowledge 에 접속한다. `/`도 이 화면으로 이동한다.
로컬 개발 화면은 자동 연결한다. UI_AUTO_CONNECT=false 또는 원격/운영 환경에서는
`.env`의 DEV_API_TOKEN 또는 유효한 API 토큰을 입력한다. DB/Wallet 비밀번호가 아니다.
운영 JWT 인증 환경에서는 해당 API에 유효한 Bearer 토큰을 사용한다.
토큰은 페이지 메모리에만 있고 새로고침/연결 해제 시 지워진다. 토큰을 URL에 넣지 않는다.

- 연결 시 최근 지식 목록을 10개씩 표시한다. 이전/다음으로 이동한다.
- 질문을 입력하고 검색하면 관련 지식을 최대 20개 표시한다.
- 범위는 비워두면 내 전체 범위, `global` 또는 `project:vector_knowledge`처럼 하나를 지정한다.
- 지식 종류와 분류로 결과를 좁힐 수 있다. 필터 변경 후 검색/목록 보기를 누른다.
- 왼쪽 카테고리와 목록에서 선택하면 오른쪽 고정폭 원문을 읽는다. 검색 결과도 10개씩 페이지로 나눈다.
- 편집 → 저장으로 원문 전체를 새 revision으로 보존한다. 사용자 편집 배지는 HUMAN으로 선언된 수정본에 표시한다. 이는 편집 경로 표시이며 사람 인증을 뜻하지 않는다.
- 동시 수정은 충돌로 거절한다. 새 수정본이 처리 중이면 먼저 완료 상태를 확인한다. 저장 접수와 검색 색인 완료는 별도로 표시한다. 오류/응답 유실 시 초안을 복사하고 이력을 확인한다.
- 제목·카테고리 편집, 새 노트 생성과 폐기는 이 화면의 범위 밖이다.
- 화면 파일은 공개이지만 지식 API는 기존 사용자 인증과 소유자 제한을 그대로 적용한다.

코드 변경 후 API를 재시작해야 화면이 생긴다. 기본은 루프백이며 인터넷 공개 배포는 별도 작업이다.

## 기존 지식에 보충하기

공통 스킬은 같은 대상·scope의 검증된 보충/정정을 기존 지식의 새 revision으로 반영하도록 안내한다.
원문과 최신 history를 읽고 유효한 기존 정보+새 내용을 합친 **전체 본문**을 revise로 보낸다.
서버가 내용을 자동 합성하는 것은 아니다. 이력은 남고 새 임베딩이 READY가 되면 검색 버전을 전환한다.
별개 주제나 단순히 유사한 기억을 임의로 합치지 않는다. 이미 설치한 스킬 사본은 저장소 버전으로
다시 설치해야 새 지침이 반영된다. 기존 전역 설정은 이번 작업에서 수정하지 않았다.

자동 연결은 loopback 바인딩/접속, 동일 브라우저 Origin, development 모드에서만 동작한다.
로컬 OS 사용자를 신뢰하는 개발 편의 기능이며 외부/운영 배포에 적용하지 않는다.

원문은 줄 번호가 있는 코드 편집기 형태다. 고정폭 코드 뷰와 줄 번호를 유지하면서 화면 너비에 맞춰 긴 줄을 접는다. 줄 번호는 원문의 논리 행 기준이며 접힌 행 높이에 맞춰 정렬한다. 줄바꿈을 끄면 가로 스크롤을 사용할 수 있다. 편집 중 Tab/Shift+Tab은 2/4칸 들여쓰기·내어쓰기, Enter는 현재 줄의 들여쓰기를 유지한다. 저장된 문장을 임의로 재포맷하지 않는다.

업무 관계가 등록된 노트는 **업무 흐름** 탭에서 RDF 그래프를 볼 수 있다. 관계명과 조건이 화살표에 표시되며 아래 관계 버튼을 선택하면 원문 근거를 확인한다. 이 그래프는 저장된 원문 버전 기준이고 편집 중인 초안을 반영하지 않는다. 원문 탭의 코드 뷰는 유지한다.

연결된 지식은 노트를 열면 현재 업무·기록 시점과 해당 노트의 scope로 자동 조회합니다.
시점 미상 관계도 기본 포함합니다. ‘조회 조건 변경’에서 과거 시점이나 다른 범위를
선택할 수 있고 ‘현재 정보로 초기화’로 돌아옵니다. 날짜 입력은 브라우저의 로컬
시간대이며 API 전송 시 UTC로 변환합니다. 현재 모드는 날짜를 고정하지 않고 조회
시점마다 서버의 현재 시간을 사용합니다. 새 노트를 열면 이전 노트의 조건은 초기화됩니다.
