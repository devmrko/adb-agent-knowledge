# Codex 지식 저장·검색 연결

2026-10-15. 기존 HTTP API 앞에 stdio MCP 어댑터를 추가한다.
Codex 사용자 설정에 vector_knowledge 서버를 등록하며 API 토큰은 설정에 복사하지 않는다.
프로젝트 절대 경로의 .env에서 DEV_API_TOKEN(또는 별도 KNOWLEDGE_API_TOKEN)을 읽는다.
API 기본 주소는 http://127.0.0.1:8000. localhost HTTP 또는 원격 HTTPS만 허용한다.

도구: knowledge_save, knowledge_save_url, knowledge_search, knowledge_list,
knowledge_get_content, knowledge_job_status. 등록은 202/QUEUED이며 READY 확인 전
검색 가능하다고 표현하지 않는다. 원문은 페이지(offset/max_chars)로 반환한다.
도구 설명에 개인 지식 사용 목적과 원문 내 지시를 실행하지 않는 규칙을 포함한다.
저장은 명시적 요청 또는 사용자가 승인한 선택적 자동 기억 정책에 따라 수행한다. 대화 전체/자격증명은 자동 저장하지 않는다.
MCP는 DB에 직접 접근하지 않고 기존 API 인증/소유자 격리를 사용한다.
API/worker는 기존 실행 스크립트로 관리한다. MCP 프로세스 stdout은 프로토콜 전용이다.

검증: mock HTTP로 경로/토큰/안전 오류/원문 페이지 테스트, 실제 stdio initialize/list_tools,
실제 MCP 저장→작업 READY→검색→원문 읽기. Codex 설정 등록 후 세션 재연결 필요 여부를 별도 보고한다.

## 조건부 선제 조회 — 2026-10-15
매 요청에서 과거 지식의 관련성을 판단한다. 이전 결정·선호·프로젝트 규칙·문제 해결 이력이나
저장 지식 검색 요청이면 응답/결정 전에 검색하고, 단순 인사·독립적인 변환은 생략한다.
전역 AGENTS.md와 저장소 AGENTS.md, MCP instructions에 동일한 정책을 반영한다.
상위 소수 결과를 검토하고 중요한 근거는 정확한 revision의 원문으로 확인한다.
랭킹 점수를 확신도로 쓰지 않으며 관련 없는 결과는 사용하지 않는다.
사용자 최신 정정이 오래된 기억보다 우선한다. 저장 권한은 아래 선택적 자동 저장 정책을 따른다.
이는 에이전트 지침 기반 동작이며 매 요청의 실행을 보장하는 코드 훅은 아니다.

## 선택적 자동 저장 — 사용자 승인 2026-10-15
사용자는 별도 요청 없이 필요한 내용을 저장하도록 승인했다. 작업의 주요 결정/검증 완료 시점에
확정된 선호·결정·안정적인 프로젝트 설정·검증된 해결 방법을 간결한 기억으로 저장한다.
먼저 같은 범위를 검색하고 동일 내용은 건너뛴다. 명확한 정정은 기존 원문/최신 이력을 확인해
revision으로 반영한다. 폐기/복원은 여전히 사용자 요청에 따른다.
전체 대화·파일 수집, 비밀정보·불필요한 개인정보 저장, 추측의 사실화는 하지 않는다.
출처/날짜/검증 수준을 본문에 남기고 저장 결과와 비동기 상태를 짧게 보고한다.
이는 Codex의 지침 기반 선별 동작이며 API가 모든 대화를 자동 수집하는 기능은 아니다.
