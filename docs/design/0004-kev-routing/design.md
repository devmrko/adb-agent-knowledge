# Kev 기반 조회·저장 판단

> 설계 당시의 결정·계획을 보존한 기록입니다. 현재 기본값·설치·지원 범위는 [현재 매뉴얼](../../README.md)을 기준으로 확인하세요. 이 문서의 계획이나 과거 검증은 현재 구현·배포 보장이 아닙니다.

사용자 요청: 로컬 Kev-4B를 사용해 개인 지식 조회 여부와 자동 저장 여부를 판단한다.
기존 vk0002 API/DB는 유지하고 MCP 읽기 도구 knowledge_decide를 추가한다.

## 흐름
조회 전 operation=lookup, 주요 작업 완료 후 저장 후보에 operation=save를 호출한다.
요청/후보 본문과 짧은 작업 맥락만 로컬 127.0.0.1:8009/v1/systemone에 전송한다.
조회는 need_lookup, 저장은 worth_saving noul 질문을 사용한다. 모델은 내용을 생성하지 않는다.
점수는 업무별로 보정된 확률이 아니며 결정론적 정확성을 보장하지 않는다.

명시적 조회 요청은 모델 없이 lookup. 저장 금지/민감정보 표시는 저장을 차단한다.
명시적 저장 요청은 비밀정보 금지 조건 안에서 save. 자동 저장은 verified=true인
확정된 선호/결정/사실/검증된 해결책만 평가한다. 모호하거나 미검증인 후보는 skip한다.
조회 점수 >=0.2는 lookup, 미만은 skip. 프로젝트의 과거 맥락이 필요하다는 확실한 근거가
있으면 에이전트는 낮은 점수를 재검토할 수 있다. 저장 점수 >=0.7은 save, <0.25는 skip,
그 사이는 agent_review다. 값은 잠정값이며 저장/조회 평가 결과를 별도로 기록한다.

모델 장애·시간 초과·잘못된 응답·입력 잘림은 agent_review로 반환하며 검색 성공/불필요로
위장하지 않는다. 모델 점수는 도구 실행이나 DB 쓰기를 직접 수행하지 않는다.
에이전트는 save 권고 후 중복 검색/원문/이력을 확인하고 저장 또는 정정한다.

## 경계
기본 타임아웃 2초, 본문 6000자 + 맥락 2000자. 루프백 HTTP 주소만 허용하며
프록시/redirect를 사용하지 않는다. 원문 로그나 지속 캐시는 기록하지 않는다.
민감 여부·명시적 지시·검증 여부는 에이전트가 입력하며 모델을 보안 필터로 간주하지 않는다.
Codex/Claude 공통 MCP와 지침으로 사용한다. 미확인 앱 훅은 설치하지 않는다.
대화 전체가 서버에 자동 전달되는 훅이 아니며 도구 호출로 연결한다.

## 검증
Mock HTTP: 경계/점수/응답 형식/timeout/422/truncation/정책 우선순위.
후속 평가: 전달받은 한국어 조회 30개와 별도 작성 저장 후보를 평가하고,
Kev와 실제 임베딩+Oracle 검색 시간을 따로 측정한다. 소규모 작성 평가셋이며 일반 성능
보장이나 전체 LLM 토큰 비용 절감을 주장하지 않는다.

## 실제 확인 (2026-10-15)
MCP 12개 도구 노출 및 knowledge_decide 실제 응답 확인.
- 인사: lookup score 0.1222 → skip, 143.0ms.
- 과거 Wallet 해결법: 0.7966 → lookup, 148.1ms.
- 확정 커밋 언어 선호: save score 0.8314 → save, 297.2ms.
- 일시적인 테스트 진행: 0.1257 → skip, 141.3ms.
- 저장 금지: 모델 호출 없이 skip.
이는 개별 동작 확인이며 통계적 품질/성능 벤치마크가 아니다.
