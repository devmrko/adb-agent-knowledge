# SQL · 처리 흐름 안내

웹 상단 버튼으로 읽기 전용 설명 패널을 연다. 실제 SQL 실행/추적 기능은 추가하지 않는다.
업무 지식, Agent Memory, 그래프, 사용자 원칙의 실행 위치·호출 경계·저장 객체를 구분한다.
SQL은 소스와 운영 스키마에서 확인한 설명용 예제이며 실제 요청 전체 SQL이 아니다.
인증 값·사용자 데이터·접속 정보를 페이지에 주입하지 않는다. 모든 값은 바인드 변수다.
SQL 직접 접근은 DB 권한으로 동작하고 앱 인증을 대신하지 않는다. 쓰기는 MCP/API 경로를 안내한다.
Agent Memory는 SQL 접근 가능하나 직접 DML은 벡터/관계/근거 일관성을 자동 보장하지 않는다.
검증: JS 문법, 전체 기존 검사, 실제 Oracle 읽기 쿼리의 빈 소유자 실행, 배포 정적 파일 일치.
