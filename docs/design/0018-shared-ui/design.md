# 공통 UI 스타일

> 설계 당시의 결정·계획을 보존한 기록입니다. 현재 기본값·설치·지원 범위는 [현재 매뉴얼](../../README.md)을 기준으로 확인하세요. 이 문서의 계획이나 과거 검증은 현재 구현·배포 보장이 아닙니다.

2026-10-19. 로컬 OwnVoice(8765)의 색상과 컨트롤 규격을 지식 노트에 적용한다.

공통 CSS common.css에는 색상·간격·글꼴·컨트롤·앱 헤더·패널을 둔다. style.css는 노트 목록/편집기/RDF 전용 레이아웃을 담당한다. 참고 서비스에 런타임 의존하지 않고 같은 origin에서 정적 파일을 제공한다. 다른 저장소의 CSS를 자동 동기화하는 패키지는 이번 범위에 포함하지 않는다.

검색/카테고리/페이지네이션/요약/상세/참조/RDF/휴먼 편집은 유지한다. API와 DOM ID 및 JS 이벤트 계약은 변경하지 않는다. 코드 편집기 줄번호와 자동 줄바꿈을 유지한다. 좁은 화면에서는 목록과 노트를 세로 배치한다.

검증: 정적 asset 응답, DOM ID 보존, 필수 저장소 검사. 브라우저 제어 연결 부재로 실제 렌더링과 인터랙션의 시각 검증은 미완료.
