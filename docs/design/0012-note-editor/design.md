# 노트 목록과 사용자 편집

2026-10-16. 사용자 요청에 따라 구현.

카테고리 선택, 왼쪽 페이지별 목록, 오른쪽 고정폭 원문 편집기로 교체한다. 검색의 기존 API/순위/상위 20개는 유지한다. 원문은 실행하거나 HTML로 해석하지 않는다.

GET /api/v1/knowledge/categories: 인증 사용자 소유 ACTIVE 지식의 분류 목록. Router → Service → Repository로 조회한다.

리비전의 edit_origin은 HUMAN/AGENT/API/UNKNOWN. 새 API 입력의 기본은 API, 웹 편집은 HUMAN, MCP는 AGENT. 기존 자료는 UNKNOWN. 클라이언트가 선언한 편집 경로이며 사람임을 인증하는 보안 속성이 아니다. vk0004는 nullable 열만 추가한다. 내용/이력 응답에 노출한다. 기본 API 값은 기존 멱등 키 해시를 바꾸지 않는다.

웹 편집은 기존 revisions API에 전체 원문과 expected_revision_id를 보낸다. 저장 직전 최신 이력과 비교하고, 서버의 동시성 검사도 유지한다. 처리 중/실패한 최신 수정은 자동 덮어쓰지 않는다. QUEUED는 저장 접수로 표시하고 READY 확인 후 새 원문을 읽는다. 네트워크 불확실성에는 자동 재저장하지 않는다. 편집 중 이동과 페이지 이탈에는 초안 유실 확인을 둔다.

검증: 사용자별 카테고리 격리, HUMAN 이력/원문, 이전 버전 보존, 충돌 거절, 마이그레이션, 브라우저 탐색/편집/재색인. 원문 편집만 지원하며 제목/분류 변경은 이번 범위 밖이다.

추가 요청: 줄 번호, 고정폭 원문, 기본 자동 줄바꿈 및 선택적 가로 스크롤, 2/4칸 Tab/Shift+Tab 들여쓰기와 Enter 들여쓰기 유지. 자동 줄바꿈에서도 줄 번호를 유지하고 접힌 행의 높이에 맞춰 정렬한다. 원문을 자동 재작성하지 않는다.

추가 요청: 원문 코드 뷰와 별도로 업무 흐름 탭을 제공한다. 선택한 정확한 활성 revision의 workflow API를 조회해 SVG 노드/방향 간선/조건을 표시한다. 관계 버튼으로 evidence를 읽는다. 순환 관계도 유지하며 레이아웃은 의미를 추론하지 않는다. 모든 텍스트는 DOM textContent로만 추가한다. 관계 없는 원문은 ABSENT 안내를 표시한다. 편집 초안과 저장된 관계는 구분한다.
