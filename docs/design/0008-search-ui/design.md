# 지식 검색 웹 화면과 보충 수정 정책

> 설계 당시의 결정·계획을 보존한 기록입니다. 현재 기본값·설치·지원 범위는 [현재 매뉴얼](../../README.md)을 기준으로 확인하세요. 이 문서의 계획이나 과거 검증은 현재 구현·배포 보장이 아닙니다.

/knowledge에서 공개 정적 화면을 제공하고 모든 지식은 기존 Bearer 인증 API로 조회한다.
화면에 토큰/DB 설정을 주입하지 않는다. 사용자가 API 토큰을 입력하며 페이지 메모리에만
유지한다. 로그아웃/새로고침 시 사라진다. 쿠키나 별도 로그인 API를 추가하지 않는다.
기본 목록(20개 페이지), 의미 검색(상위20), scope/종류/분류 필터, 정확한 revision 원문을 제공한다.
저장/수정/폐기 버튼은 이번 UI 범위 밖이다. 데이터는 textContent로 렌더링하고 외부 리소스를
불러오지 않는다. CSP self, frame-ancestors none, no-store를 적용한다. 오래된 비동기 응답은
AbortController와 요청 번호로 무효화해 로그아웃/다음 검색 후 다시 표시되지 않게 한다.

공통 스킬/프로젝트 지침/MCP 설명에 '동일 대상·scope에 대한 검증된 보충은 원문+이력 읽기 후
기존 유효 내용을 유지한 통합 본문으로 revise'를 명시한다. 별개 사실/불확실한 유사성은 병합하지 않는다.
revise는 전체 본문 replacement이며 서버의 자동 의미 병합은 아니다. 충돌이면 최신 이력을 다시 읽는다.
