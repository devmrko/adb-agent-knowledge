# 다른 머신의 Codex/Claude 메모리 정책 적용

2026-10-16 사용자 요청: 현재 머신에 적용한 지식 DB 중심 메모리 정책을 다른 머신에서도 실행하도록 Git으로 배포한다.

표준 라이브러리 CLI `scripts/configure_agent_memory.py`와 공통 글로벌/프로젝트 정책 템플릿을 제공한다. 기본은 변경 없는 계획 출력이며 `--apply`가 있어야 쓴다. 홈과 검색 루트를 인자로 받아 절대 개인 경로/DB ID를 배포하지 않는다. `--allow-auto-save`, `--disable-claude-auto-memory`는 명시 선택이며 기본 적용은 권한을 확장하지 않는다.

글로벌 AGENTS/CLAUDE와 프로젝트 AGENTS/CLAUDE(override/local 포함)의 관리 블록만 생성·교체하고 나머지는 그대로 보존한다. 루트 중복을 제거하고 symlink 경로·파일은 따라 쓰지 않는다. Git 내부·의존성·캐시·시스템 폴더를 제외한다. MEMORY.md 및 에이전트 memory 디렉터리는 목록으로만 보고한다. 기존 지식의 DB 이관·삭제·자동 요약 업로드를 수행하지 않는다. 별도 가이드에 MCP 원문 비교→이력 보완→READY·정확한 내용 확인→참조 교체 절차를 명시한다.

변경 전 모든 대상과 JSON 설정을 검증한다. 백업은 Git 밖 사용자 로컬 상태 디렉터리에 권한 제한으로 생성하고 manifest에 전후 hash를 기록한다. 복원은 적용 이후 내용이 바뀐 파일을 거부하고 원본만 복원한다. DB 연결·스키마 수정·서비스 재시작·다른 저장소 push는 하지 않는다. 스킬/MCP 설치는 기존 설치 명령을 재사용한다.

검증: 임시 홈에서 dry-run 무변경, 기존 규칙/JSON 보존, 재실행 멱등, symlink 제외, 중복 루트, native auto-memory 선택, 백업/복원 및 동시 수정 보호. 실제 머신에는 계획 모드로 검증한다.

검증 완료: 2026-10-16 전체 137개 pytest, Ruff check/format, mypy 통과. 임시 홈에서 적용/복원·멱등·기존 설정 보존·동시 수정 보호를 검증했다. 실제 체크아웃에서는 preview만 실행하여 기존 관리 블록 밖 정책 2건을 경고하고 쓰기를 하지 않는 것을 확인했다. 다른 머신의 실제 실행은 아직 수행하지 않았다.
