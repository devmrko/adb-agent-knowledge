# v0.3.0-alpha.1 — Agent Knowledge for Oracle ADB

2026-11-04 · **Prerelease / 알파** · Python metadata: `0.3.0a1` · HTTP API version: `0.3.0-alpha.1`

## 목적과 포함 범위

Oracle ADB를 에이전트의 공통 지식 저장소로 쓰는 공개 알파입니다. MCP/API, Kev 판단, 한국어 벡터·키워드 검색,
요약·상세 원문·인덱스, 버전과 감사 이력, 선택적 RDF/SQL Property Graph, Oracle AI Agent Memory를 제공합니다.
문서 첫 화면을 목적 → 사용 효과 → 기술별 역할 → 흐름 → 설치 → 상세 안내로 정리하고 한영 설명을 맞췄습니다.

기본 agent 모드는 호출하는 Codex·Claude가 관계를 추출합니다. 별도 생성형 LLM은 service 모드에서만 필요합니다.
Kev와 임베딩은 별도 역할이며, 클라이언트 훅을 등록해야 매 요청의 기억 확인 절차가 실행됩니다.

- 별도 시험 프로세스를 SDK staging 후/최종 DB commit 전에 종료하고, Oracle 드라이버 연결도 끊어 복구했습니다. 이전 버전 유지·재처리·이력 보존을 확인했습니다. 운영자 복구이며 자동 복구나 실제 장기 네트워크 장애 시험은 아닙니다. [복구 설계·검증](../design/0046-v3-recovery/design.md).
- 공통 RDF G_ID 필터 복원 후 동일 그래프 포함 요청은 19.888초에서 재시작 첫12.809초, 반복1.376/1.387초였습니다. 관계6개·근거·경로는 같았습니다. 소수 표본이며 전체 검색 성능 보장은 아닙니다.
- 릴리스 준비 시 로컬 정적 검사·타입·테스트와 문서 링크 검사를 수행합니다. 최종 실행 결과는 아래 release verification에 기록합니다.

## 남은 일

1. 인덱스·옛 워크플로우 RDF의 별도 GET_MODEL 경로 측정과 필요시 개선.
2. 최종 graph_mode=auto 설정으로 Claude 실제 훅/후속 요청 재검증.
3. 역사적 문서·기억에서 현재 상태와 지난 관찰을 구분하는 정리. 이번 README 정비가 전체 정리 완료를 뜻하지 않습니다.
4. 30질의 검색 비교의 공개용 재현 결과와 실패 분석 정리. 일반 품질 향상 주장으로 사용하지 않습니다.

새 ADB 서비스 생성, 모든 OS·GPU 조합, 대규모 부하, 조직 공유 ACL, 자동 재임베딩, Oracle Text/BM25와 OCR은 이 알파의 보장이 아닙니다.
업무 상태와 정책을 비교하는 [actionable knowledge](../design/0047-actionable-knowledge/design.md)는 제안이며 구현되지 않았습니다.

## English

This alpha lets agents use Oracle ADB as a shared knowledge service: MCP/API, Kev decisions, Korean-capable
vector/substring retrieval, indexes, source revisions/audit, optional RDF/SQL Property Graph and Oracle AI Agent Memory.
The READMEs now introduce purpose and user outcomes before implementation details and setup.

Use the [English setup](../../README.en.md) and [v3 migration/rollback guide](../guides/v3-primary-store.en.md).
The package version is `0.3.0a1`; tag/API version is `0.3.0-alpha.1`. Schema head stays `vk0016`. Existing
installations retain the legacy default until v3 is explicitly initialized, migrated and enabled. Models,
credentials and private knowledge are not distributed. Publishing this release does not auto-upgrade deployments.

Previously recorded live validation covers an empty schema in an existing ADB, real embeddings and graph
queries, 462 transferred source versions, and isolated process/connection failure recovery. Recovery is manual;
it is not an automatic failover or prolonged network-outage guarantee. The restored native RDF filter preserved
six edges/evidence/paths while reducing one repeated request from 19.888s to about 1.38s; the first post-restart
call took 12.809s. These small samples do not establish general search performance.

Remaining work: measure other RDF read paths; recheck Claude with final auto graph routing; reconcile historical
docs/memories; publish sanitized 30-query evaluation and analyze misses. The proposed business-condition evaluator
is not implemented. All-OS/GPU support, large-scale performance, organizational sharing ACLs, automatic
re-embedding, Oracle Text/BM25 and OCR are outside this alpha's validated scope.
